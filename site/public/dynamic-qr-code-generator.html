Dynamic QR code generator with analytics

A dynamic QR code points to a short QRForge link that redirects to your destination. The printed code never changes, but you can change where it goes at any time and see how many people scanned it.

What dynamic codes add

  • Edit the destination without reprinting
  • Pause or resume a code
  • Scan history by date, device, operating system and browser
  • Destination safety score and link health checks
  • On higher plans: smart rules by device or schedule, password protection and A/B destinations

Never-dead promise

If you cancel a paid plan or reach a limit, your printed dynamic codes keep redirecting to the base destination. Premium rules pause, but the code does not die.

Important to know

Dynamic codes depend on the QRForge redirect being online. For information that should work forever with no dependency, such as Wi-Fi or a contact card, use a static QR code.

Frequently asked questions

What is the difference between static and dynamic QR codes?

A static code holds the data itself and never changes. A dynamic code holds a short link, so you can edit the destination and track scans.

Can I track how many people scanned my QR code?

Yes, dynamic codes record scans with date, device, operating system and browser. Visitor IP addresses are not stored.
